# Financial Market Dynamics: Statistical Modelling, Econometric Analysis and Time-Series Forecasting of the S&P 500 (2016–2026)

## 1. Project Overview

This project investigates the relationship between financial market indicators and S&P 500 returns using statistical modelling, econometric analysis and time-series forecasting.

The research examines whether selected financial indicators can explain fluctuations in S&P 500 returns and evaluates the extent to which historical market data can be used to forecast future market movements.

## 2. Research Question

To what extent can financial market indicators explain fluctuations in S&P 500 returns, and how effectively can historical market data be used to forecast future market movements?

## 3. Financial Indicators

The analysis uses five financial time series obtained from the Federal Reserve Economic Data (FRED) database:

* S&P 500 Index
* CBOE Volatility Index (VIX)
* 10-Year US Treasury Yield
* Brent Crude Oil Prices
* Federal Funds Rate

Study period: October 2016 – October 2026.

## 4. Methodology

The project is divided into three main phases.

### Phase 1: Data Acquisition and Preprocessing

* Financial time-series data acquisition.
* Dataset integration and construction.
* Missing-value treatment.
* Feature engineering.
* Outlier identification and analysis.
* Final dataset preparation.

### Phase 2: Statistical and Econometric Analysis

* Descriptive statistics and exploratory data analysis.
* Covariance and correlation analysis.
* Simple and multiple linear regression.
* Regression diagnostics and assumption testing.
* Statistical inference and model evaluation.

### Phase 3: Time-Series Analysis and Forecasting

* Time-series decomposition.
* Stationarity testing.
* ARIMA modelling.
* Forecast generation and evaluation.
